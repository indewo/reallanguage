# 录音与截图导入 · 设计基准

两张初级设计稿共用 **2340 × 1080 px** 的横屏母版，宽高比固定为 **13∶6**。设计评审和 PNG 交付以这个尺寸为准。

## 共用页头

下列坐标均以母版左上角为原点，单位为像素。

| 元素 | 在母版上的位置和样式 |
| --- | --- |
| 页面标题 | 以整屏中线 x=1170 居中。两页文字使用同一字号等级、字重和基线，字形可见区为 y=62–114。使用产品 Noto Serif SC 粗体与深海军蓝 `#071A33`。 |
| 返回 | 箭头中心在 x=255、y=94，作为左侧独立操作。 |
| 标题下划线 | 使用产品已有的陶土红手绘笔迹，与标题居中，笔迹中心约 y=136。线长随标题字数变化。 |
| 页头分隔 | y=174 的细分隔线标出正文起点。右侧的「添加截图」使用独立操作位，标题仍以整屏居中。 |

## 页面布局

- **录音**。在页头下方依次排布录音状态、计时和「单次录音上限 60 分钟」。波形位于中下部，「暂停录音」与「结束并转译文字」位于底部操作区。
- **截图导入**。中间区域承载截图网格，设计母版展示四列。每张截图有顺序编号、拖拽手柄和删除入口。顶部可添加截图，底部主操作统一显示「识别上传截图」。启动识别后保留当前页和列表位置，同一按钮显示加载圈及「正在导入中」，处理期间防止重复提交。超出可视高度时滚动网格。
- **导入音频**。沿用同一页头和底部操作区。初次进入从「选择音频文件」打开文件选择器。选好一个文件后，卡片显示文件名、总时长、试听和播放位置，右上提供「更换文件」。底部「转译音频」启动后在原位显示加载圈和「正在转译文字」，完成后进入共用的中英对照选句流程。

截图网格处于静止状态时，右侧滑动提示淡出。滚动时滑块沿网格右边缘浮现。列表在顶端时滑块与网格顶端对齐，滑块长度随可视高度占内容总高度的比例变化。松手停稳后淡出。识别前后沿用同一网格和滚动位置。截图卡的圆形删除键、拖拽圆点和按钮内的加载圈均按 1∶1 绘制。

## 前端适配

实现时由窗口的实际可用宽高、系统安全区和字体缩放决定布局。标题居中，页头和底部操作优先分配空间。截图网格根据可用宽度确定列数，以滚动承载更多截图。录音页在紧凑横屏下先收敛纵向间距与波形高度，并保证两个底部操作可达。文字使用可缩放字号，图标和装饰按原比例绘制。
