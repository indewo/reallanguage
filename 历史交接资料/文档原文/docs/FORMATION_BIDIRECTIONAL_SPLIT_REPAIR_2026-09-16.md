# 内容形成双向回溯与拆分修复

## 验收边界

- 内容形成流程可从任一生成阶段持续返回，直至原始可编辑页面。
- 页面内返回按钮与 Android 系统返回键使用同一套后退规则。
- 返回后重新向前时，只有与当前原文和选择完全匹配的缓存可以复用。
- 非空原文不得进入“内容拆分没有完成”终止页。
- 拆分结果必须顺序连续、每个单元符合最小语义粒度，且拼接后与原文逐字一致。

## 修复策略

1. 服务端先采用模型拆分；首次结果不合格时只进行一次稳定身份的纠正请求。
2. 模型、网络、缓存或纠正请求仍失败时，服务端使用确定性边界规则完成无损拆分。
3. Android 客户端独立复核服务端结果；伪完成、粗段落、缺字、改写、乱序均改用本地无损拆分。
4. 会话缺失或弱网时，Android 直接本地拆分，不上传原文，也不中断流程。
5. 最终固定页缺少旧版恢复快照时，返回英语确认页重新形成目标，不再拼装缺字段页面。
