## 已发现的布局原因

1. 自然高度容器内的背景图片用 `fillMaxSize` 参与父容器测量，反过来撑大卡片并把操作挤出首屏。改为不参与内容测量的背景层。
2. 固定高度数字、纸签、说明卡没有考虑真实字形行高与系统放大；逐个替换为自然高度或按字体扩展，而不是删文字。
3. `IntrinsicSize` 父容器包含子组合测量组件造成账号页崩溃，已拆除冲突测量。
4. 词汇展开自动定位到详情底部，词头与音标被滚走；定位改为对应词条身份区。
5. 字母导航在短可用高度下被平均压缩；短屏/大字改为可滚动完整索引，普通宽屏保留全量及 Dock 反馈。
6. 句式详情用 FlowRow 的权重加最小宽度导致本应并排的两块变成整行；改为明确可用宽度判断并排/堆叠。
