## 返回语义与统一原则（待集中确认）

| 操作 | 统一建议 | 必须保留的行为区别 |
| --- | --- | --- |
| 返回／返回首页／返回账号／返回消息／返回注册 | 与新设置页一致的左箭头、深色、原生衬线文字，固定左上；普通页显示“返回”，可访问描述说明去向 | 保留原目标，不能所有按钮都改成回首页 |
| 返回修改／返回修改问答／返回重点句选择 | 同一箭头与字体，保留能说明目的的文案 | 可能保留草稿及回到指定阶段，不是任意上一页 |
| 退出学习／返回当前任务 | 同一箭头风格；“退出学习”保留明确文字，位置结合学习页统一 | 学习退出确认、保存/恢复进度与任务内返回不同；先查实际回调和确认流程，不直接替换成无确认返回 |
| 取消修改／取消录音／放弃章节 | 不作为普通返回自动合并 | 可能丢弃内容或改变章节状态，要保留确认及区别 |
| 退出登录／注销或删除账号 | 不属于本轮同义返回 | 会影响登录或数据，继续使用独立账号操作与确认 |
| 收回详情／展开／上一句／下一句 | 不属于页面返回 | 保留内容控制含义，不因为使用箭头就批量替换 |
