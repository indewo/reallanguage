# v109 · 从生活素材进入英语学习

首页每次打开时，「开始录音」位于正中。向后依次为「对话截图」「导入音频」「AI设定场景」「日常记录」，第五张和第一张相接。左右箭头和手势都能双向循环。日常记录打开已有日记编辑器，AI 设定场景打开已有场景页。首页底部四个原功能各有独立入口。设计基准为横屏 2340 × 1080，运行时按可用空间适配。

## 首页卡片

五张纸卡共用同一个滑动位置。拖动时，居中的卡逐渐退到侧边，同侧的下一张卡从后方抬起并展开；最远端的卡从纸叠后方绕到另一边。慢拖时可以停在两张卡交接的任意位置，手指反向会沿原路径退回。松手后就近落定，也可以打断尚在进行的切换。侧卡就位时，五个入口的标题都能看到。

点左右箭头依次切换，点任何露出的卡片直接进入对应功能。每次重新打开首页，录音卡默认居中。底部从左到右为「词汇本」「句式本」「统一回顾」「继续未完成学习」，有待回顾任务时显示「统一回顾已到期」。拖卡时页头与底部四个入口固定。

## 采集及导入

| 入口 | 用户操作 | 处理与结果 |
| --- | --- | --- |
| 开始录音 | 首次授权麦克风后录制，可暂停和继续。单次录音上限为 60 分钟，暂停时间从计时中扣除 | 「结束并转译文字」完成录制，在当前页显示转译状态。成功后进入「选择学习短句」 |
| 对话截图 | 选择实际图片，继续添加、删除或拖动更换顺序。可滚动浏览 | 「识别上传截图」在原位置变为「正在导入中」。设备先按图片顺序识别文字，再将识别出的文本生成中英对照 |
| 导入音频 | 在「导入音频」页选文件、核对时长、试听、拖动播放进度或更换文件 | 「转译音频」在当前页进入处理状态。音频可由现有转录服务处理。MP4 仅读取音轨。成功后直接进入共用选句页 |
| AI设定场景 | 沿用既有场景入口和内容确认 | 已确认的场景进入共用中英对照 |
| 日常记录 | 沿用日记编辑器 | 提交内容进入共用中英对照 |

首版验收文件为 MP3、AAC 音轨的 M4A、PCM 编码的 WAV、包含 AAC 音轨的 MP4。选择文件、播放、替换、退出与转译是不同操作。把文件交给服务的操作是用户点击「转译音频」。失败时保留可重试的输入。

日常记录继续使用现有日记编辑器的输入校验（300 字、最多 10 句）。这仅作用于日记录入。截图及录音全文也可进入同一套语义分段流程。

## 已确认的分段与学习规则

1. 一段承载一个可以理解的场景或小任务。同一件事的提问、回应、澄清可以留在一起；话题、任务或交谈目的切换时另起一段。说话人轮换本身不触发分段。
2. 原段较长时，先寻找一个问题得到回答、一个安排已经商定或一项行动自然结束的位置。切开后两边都应能理解。依赖前文的条件、否定、指代、转折与必要解释和它依赖的内容放在一起。
3. 复杂的单句可以独立成段；短材料可以只形成一段、一个学习句。没有按字数、标点个数或句数强制切段的产品阈值。模型请求按容量分批传输时，仍须在跨批次位置复核语义连续性。
4. 先按整段生成自然美式英文，保持事实、语气、时间关系、说话人和原意。再阅读完整英文，在英语内部确定学习句边界。右侧按顺序呈现完整英文，逐句朗读。原材料已有英文时应保留原表达并生成相应的中文。
5. 正文左侧是整段中文，右侧是同段英文。取消「中文段落」「英文段落」「短句选择」栏头与段落编号。两栏按段一起向下滚动，选择数和继续按钮固定在底部。
6. 全文合计选择 1–3 个英文学习句，支持跨段勾选和取消。点喇叭每次朗读一次，选句与发音互相独立。后续学习使用选中的英文；所选位置不连续也无需据此另开章节。

### 例子

「我周四下午要带孩子看牙，赶不上咱俩的会。你周五上午有空吗？要是方便，我来改邀请。」可放在同一个改约场景中。自然英文可写成 “I can’t make our meeting Thursday afternoon. My kid has a dentist appointment. Would Friday morning work for you? If that works, I’ll update the invite.” 最后一句保留条件与承诺。紧接着出现「对了，报销收据发给谁？」时，转入新的段落。
