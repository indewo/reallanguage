# 学习页面衔接设计提案

2026-11-24。来源：用户反馈学习页面衔接、跳转生硬，要求本轮验证后思考设计。**提案待集中审视，尚未实现、尚未实机验收动画。** 首页现有动态效果继续沿用；本提案不重画已确认页面。

## 当前观察

- 已从未完成学习真实入口恢复咖啡店章节，查看基础讲解。纸张背景、句子上下文和练习正文已有共同视觉语言，适合保留位置、局部换内容。
- `ProductionApp.kt` 的学习路由按分支直接替换 Composable，例如讲解准备完成立即进入讲解、抄写完成进入听写；该层没有统一的学习过渡容器。此为代码观察，不是对所有设备卡顿原因的性能诊断。
- 不同阶段分别使用 `ChapterLearningFrame`、`ChapterWritingFrame`，句子高度、正文空间与操作区域各自布局。只给整页叠加淡入淡出，仍会保留位置跳变，还可能让已隐藏答案短暂残留。

## 建议采用的体验

同一句的练习像在同一张桌面上换一份练习内容：背景、退出入口、句子纸条位置稳定，阶段标题和正文温和接续。按钮点下立即反馈；等待和结果都在原来的练习区域呈现。仅在换句、换章时用稍明显的方向变化。

以下时间是初始设计值，实施时由真机观感调整，不作为用户必须等待的时长。位移单位为 Android dp，不随截图像素直接放大。

| 场景 | 保留的内容 | 变化与节奏 | 用户操作 |
| --- | --- | --- | --- |
| 同一句：讲解 → 朗读 → 抄写 | 背景、句子纸条、退出入口、操作区边界 | 旧正文约 80ms 淡出；新正文约 140ms 淡入并向上归位 8dp，总计约 220ms；标题同时短淡变 | 一次点击推进一次，主操作始终靠右 |
| 抄写 → 听写；进入独立复述 | 背景、纸条尺寸和中文上下文 | **先立即移除禁止显示的英文及相关例句**，再切换正文；英文不参与跨页叠化，不从答案页截帧做动画 | 动画期间不触发输入、不播放上一阶段音频 |
| 同阶段下一轮／切换词语讲解 | 整页框架、纸张、按钮区域 | 只换词语、轮次或反馈块，约 140–180ms 淡变，不重播整页入场 | 输入与录音状态由实际业务结果决定，不因动画重置 |
| 获取讲解／提交评价 | 当前句子与练习区域 | 点击后按钮立即显示真实忙碌状态；若持续等待，正文显示同尺寸占位或现有进度；就绪直接衔接内容 | 不另加全屏中转页，不制造百分比，不为动画延迟结果 |
| 评价完成 → 下一步 | 用户刚得到的结果 | 结果在原位短淡入；保持可阅读，点“继续”才离开 | 不自动闪过成功、识别确认或评价结果 |
| 下一句／下一章 | 纸色、公共入口和操作区 | 内容向前轻移 16–24dp，约 240ms；换章保留明确的新章标题 | 使用现有完成/下一步操作，不新增一道确认 |
| 返回／退出后恢复 | 已保存输入、轮次、反馈、滚动位置 | 返回采用相反的轻移方向；恢复首帧先有可识别上下文 | 退出确认规则沿用，不因过渡自动保存为已完成 |

不加入翻书卷页、3D 旋转、全屏缩放或反复庆祝动画。前面的页面已出现过透视挤字问题，学习区应优先保证文字稳定、清晰。

## 布局与加载一并处理

1. 同一句的上下文纸条采用统一位置和可用高度规则。长句在可用空间内正常换行/滚动，不能为固定高度裁字。切换阶段时不反复伸缩整张纸条。
2. 底部操作区域采用统一的对齐和主次关系。保留“发音”“播放”“清空”等各阶段必要动作；同位置按钮换义后，上一轮触摸不能落到新按钮上。
3. 切换只由已提交的业务事件驱动。网络未完成时不先跳成功页；失败在当前区域显示可操作的错误和重试入口。
4. 上一阶段音频及时停止，新音频只由新阶段实际播放规则启动。动画重组不应重新录音、重发评价、重复生成音源或增加扣费。
5. 键盘在新页面需要并稳定后才请求焦点。返回保留原输入，不用键盘升降制造额外页面位移。
6. 尊重系统动画关闭/减弱设置；动画关闭时即时切换，用户仍能明确看到阶段标题与可用操作。辅助功能不同时读到前后两页。

## 建议实施顺序与验收

先做两个代表场景的小范围实机版本：**讲解 → 朗读**（上下文保留）和 **抄写 → 听写**（答案隐藏、键盘、音频）。审视后再扩展其余学习阶段，避免一次性改变整条学习链。

实现边界建议在学习专用容器中统一管理阶段标题、上下文和操作区；正文切换身份包含章节、句子、阶段及必要轮次。不要在全局路由外直接包裹全部页面并让旧页面持续运行。

验收需使用真实学习记录完整推进，并录屏逐帧检查：

- 普通句、长句、150% 字号都不裁字，纸条和按钮不突然跳位。
- 点按、连点、返回、网络慢、失败重试均只执行一次业务动作；页面没有白闪或旧结果覆盖新结果。
- 听写与独立复述的第一帧起都没有被禁止的答案；旧页面不接受触摸或辅助功能焦点。
- 录音、播放、键盘、学习进度和重开恢复保持正确，费用记录无重复调用。
- 评价结果可完整阅读；用户明确点继续后才离开。
