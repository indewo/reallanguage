# 场景页面设计与实现

- [AI 设定场景](scene-home-v1.png)为审视稿。现有推荐取自近 90 天已归档的最多 12 份资料，按来源日期排序，保留最多 4 条。画稿展示的是两条示例。建议零条时隐藏推荐区，一条时展示单卡，三至四条时横向分页。该入口改版尚未接入代码。
- [补充场景细节](scene-details-v4.png)为用户确认稿。左栏只保留场景名称与通用笔记本拼贴。右栏使用文字单选纸片，按可用宽度排布，长选项独占一行，选项区可滚动。选中预设后直接确认，自填时才显示输入框。通过上一问查看或修改历史。
- [生成场景内容](scene-generation-v2.png)为用户确认稿。复用同一幅通用拼贴。正在编排时在图标外显示旋转弧。完成信息整理后进入后台请求，收到有效响应后进入草稿校验。后台单次请求内部的模型生成与审核没有另报百分比。
- [学习目标加载稿](../target-loading-review/target-loading-v1.png)已接入。三个阶段由准备重点句、发起提取请求和校验并整理返回结果驱动。失败保留所在步骤和恢复操作。

使用内置 image_gen 参考已确认的学习目标整理页生成三张设计图。要点为奶白毛边纸、深蓝宋体、陶土与橄榄色、保留动态标题与通用无字插画。细节页按用户反馈逐轮去掉选项配图、预设选择后的重复输入和左栏历史回答。生成页将咖啡插画替换为通用笔记本。程序只接入一张独立透明拼贴，标题、选项、按钮和加载均由界面控件绘制。

## 生成失败

公网日志的短文失败请求多次返回 500，原因是 `Scene unit is too long for focused learning`。例如请求 `889654b7-875f-4b01-8d7e-5f3b47c1e136`。后端把可拆分的超长短文按标点自然边界重新分段，保留原文和事实引用，并继续执行原有段长、总段数和事实一致性检查。不可安全拆分或超过总段数的内容仍返回失败。公网只替换了场景生成应用模块，保留原文件备份，未迁移数据库。

资源引用审计确认旧学习目标海报和旧场景选项纸片无引用，移除源文件共 4,577,016 字节。保持一份通用插画供三个页面使用。
