## 真实验证与隔离验证

设备：已授权 OPPO PFFM10，Android 15，2400×1080 横屏。覆盖安装保留原账号、录音与学习数据；没有卸载、清数据或调用账号注销。

真实流程：

1. 首页 → 设置 → 基础词池六级改高中 → 表达风格显示高中 → 固定左上返回显示未保存提示 → 保存并返回 → 选择“从下一份内容生效” → 首页。
2. 覆盖安装最新实现 → 重开设置 → 表达风格仍为高中；再从此页入口改回六级，同样保存并重开确认六级。未生成新学习材料、未覆盖已确认内容。
3. 首页 → 账号 → 管理本机录音，列表显示现有两条录音；未播放、删除或导出私人录音。
4. 首页 → 消息 → 查看空状态与三个筛选 → 固定左上返回首页。此账号没有可用于真实非空读写验证的消息。
5. 设置四页签实际切换并截图查看；提醒滚轮 20:00 选择为 20:01，确定后时间进入草稿，放弃修改重开确认原 20:00、关闭状态保持。

## 首页动效提案（独立于当前 App）

方向：纸片平移接替主位。保留当前五个入口和静态素材，纸片文字不随透视被挤压；切换约 260 毫秒、减速收尾，无弹跳、自动轮播或 hover 阴影。拖动跟手，松手按位移和速度决定落在哪一张；未达到阈值回原位。用户再次拖动即可接管进行中的切换。减少动态效果模式取消位移，仅立即切换焦点。

这是动效交互方向，尚未交付可操作新原型，未替换当前首页动效；不得描述为新动效已实现或已验收。
