## 3. 产品完整链路

### 账号与首页

账号入口 → 注册/验证或登录 → 首次设置（词池、使用偏好、语音）→ 首页。后续设置走独立入口。学习入口包括写日记、快速录音、AI 设定场景；首页另有继续未完成学习、统一回顾、词汇本、句式本、消息、账号/费用等。账号/网络检查不能被冒充内容保存成功。

### 三个内容来源

1. **日记**：输入中文或输入法语音 → 确认来源 → 后台整理、安全检查、语义拆分 → 重点句选择。输入法语音是 IME 的组合文本更新，不是 APP 自带听写；不能把每次部分识别结果重复追加。文本框按真实折行伸缩，删短后收回；不能只给一行高度而要求框内滚动。
2. **快速录音**：说明/权限 → 开始录音（基线最长 2 分钟）→ 停止/试听 → 用户选择转写并继续 → 查看与修正中文 → 共用形成链路。失败保留音频；删除须走确认，不能让失败清空来源。
3. **AI 场景**：最近推荐/公开模板/直接描述 → 对话或短文 → 逐次补充细节 → 生成中文 → 用户检查编辑 → 共用形成链路。优先截取一个有交流价值的真实小场景，不把整段经历写成摘要作文。用户明确要求问题量在 3–10 范围内，并持续判断信息是否足够；已有一两个完整场景即可生成，不为凑满 10 个问题继续索要店名等无关信息。不要把“未知”视为所有内容都不可生成。

### 三来源共用的形成链路

确认中文 → 安全检查 → 必要的后台语义拆分 → 展示全量中文单位并选择重点句 → 形成章节 → 生成并确认英语表达 → 提取并选择学习目标 → 确认并固定 → 共同学习。

- 后台“整理日记”“内容拆分”“保存进度”仍有必要逻辑，但用户已要求删除其独立过场页面。留在前页显示操作中状态，完成后直接到下一业务页；不能额外生成只用于过场展示的 AI 内容。
- 全量中文来源不能漏句。每个重点句必须保留对应中文；确认英语页面不能只显示有多个候选的句子，单一合格表达也需正常展示。多个表达选项以同组最长内容确定一致的卡片尺寸。
- 英语按语境、目的和真实美国人说法表达，保持用户事实与原意。日记/录音语境不全时可补全交流背景，但不能擅改地点、人物、时间、经历为已确认事实。保真检查要针对语义，不是逐词硬译。
- 基线选 1–3 个重点句；每章围绕重点句与必要上下文，通常 3 句、最多 4 句。较长表达拆成可学短句，不能截掉意义或拆坏英文单词。
- 上方 AI 优选目标是多选；勾选状态清楚，中英文、词类、解释、例句完整。下方“其他可添加词或词组”仅补充 AI 未选出的目标，排除上方已有项及重复词形。取消目标不意味着取消句子学习，但已要求删除页面上的冗余提示文案。
- 固定时保存确认的来源、英语、重点句和所选词义/搭配/句式；后续只用已固定内容。未选目标不能自动混入学习。

### 章节学习顺序

共同学习导览 → 基础讲解 → 读＋说 → 手写抄写 → 音频听写 → 整句会说 → 句式会说（无选中句式则不出现）→ 完整书写 → 场景回应 → 本章学习结果与归档 → 下一章边界/返回首页。

- **基础讲解**：展示整句与当前目标的词义、用法、例句。进入或切换句子自动自然朗读两遍即停，点击发音再读；不自动念“这句表示”之类说明，不无限循环。返回/发音/我理解了同排等高。目标“会了”在卡片内右下，内容不足一屏不应空滚动。
- **读＋说**：手触英文并沿句子滑动即开始录音；滑完后点录完，不能先强制点“读一遍”。保留完整单词及指读空间。录音评价不能仅凭用户点完成伪造发音结论。
- **手写抄写**：两次练习；次数小字单行置于模块下方。笔迹严格裁剪在纸内。只在本页保留，不上传、不识别、不判错。
- **音频听写**：听当前句并输入完整英语；提示属于帮助，不能与无帮助通过混算；大小写差异不算错。提示按钮实际功能需按合同与实现核对，不能只有按钮无反馈。
- **整句会说**：基线五次（中英文跟读 2、英文朗读 2、独立表达 1）；前四次是训练反馈，第五次才按独立能力规则评估。反馈明确标注 AI 反馈，按可证据支持的词句问题细分，不编造无法测出的发音结论。每轮录音只有一次明确提交/恢复操作，不能连续要求两次“重试”。
- **句式会说**：为已选句式提供新情境练习，按基线 1–5 个场景；不强迫学习未选句式。训练与独立判定区分。
- **完整书写**：每句先有声后无声，再完成全章最终批次；删除无意义阶段标签、打字机图和装饰性标点，留足写作空间。查看/播放属于帮助，影响独立结果资格。空白不是答案。
- **场景回应**：展示合适情境与上句，录音后就地显示“正在检查”和 loading，避免看似卡死。图片按目标比例构图/裁切，不拉扁人物。达到本章必要结果后才归档。
- **结果**：基于实际保存的整句、词义/搭配、句式、订正情况展示，不硬造数量。已要求去掉“结果保存在本机”等冗余文案，徽章、按钮在对应模块内对齐。

### 返回、暂停、放弃、回顾

- 返回遵循真实前一个流程节点，逐级可回溯，不突然进入不相关“已完成只读”页面。后台正在执行时防重入并保留状态。
- 已完成步骤的只读查看用于回顾已完成内容，不能修改正式结果；它不等于普通返回的唯一替代路由。
- 退出学习入口固定在标题区域，与重点句角标分离。退出选项是继续、保存当前步骤暂时退出、进入放弃本章确认；三者后果不同。
- 普通学习保存检查点后从“未完成学习”恢复；放弃未完成章不能删除既有归档、其他章节或共享词义学习记录。
- 基线统一回顾在 3 个实际普通学习日后形成队列，每日最多 3 个不同重点句，按未完成能力练习。完成章提交；中途退出的当前回顾章临时状态不冒充完成，已完成章保留。
- 费用不足、认证失效、网络故障分别处理；重连后回原节点。不可把本机损坏或 AI 合同校验失败全叫“连接不可用”。

## 4. 离线词库与状态

八个并列词池：初中、高中、四级、六级、考研、托福、雅思、GRE。不是难度与偏好两套重复选项，移除专八等旧分类。原始 DOC/XLS/XLSX 都有来源，不限 Excel。

总表存“英文＋词类＋释义＋所属词池”。完全同词、同词类、意思接近时可用任一来源原释义合并，不自编翻译，也不为减少数量删掉必要义项。初中先排序再合并。预生成池索引/字母索引/词形查找，APP 不需联网、不每次扫描总表、不用 AI 才能定位。检查词形或时态后再取释义，避免全表反复遍历。

当前词池显示该池全量词/词组与适用义项；同词同词类同义在其他池学过则共享状态，不同新义仍未学。状态机以 SPEC、数据模型和实际类型为准，不为 UI 自造“已验证”等不受支持状态。句子不是词，整句不能误写入词汇本。字母 A–Z 完整、可触摸滑动定位、有放大选中反馈，无中间省略号；从对应字母首词开始。单词不能断成两行；字号/列宽按最长词及实际可用宽度设计。发音仅图标，位置固定，标准美音。查词栏常驻单行、清空/查询扁小等高；列表按内容增高并支持分页加载（用户建议每 200 项），卡内不得截断或二重滚动。

## 6. 代码、数据与联网架构

主要目录：`apps/android`（Kotlin/Compose），`apps/api`（鉴权与接口），`apps/worker`（长任务），`apps/scheduler`（周期任务），`apps/admin-web`（运营审核），`packages/backend-modules`（领域模块），`packages/contracts`（合同），`packages/observability`，`packages/test-support`，`tooling`（构建、排查工具）。Android 具体数据适配以代码为准，旧架构写 Room 并不证明当前每条路径都用了 Room。

架构基线是模块化单体 API＋独立 Worker/Scheduler，PostgreSQL 保存账号/设置/审核/operation/消息/账本；模型、ASR、TTS 使用可替换供应商适配。耗时任务用稳定 operation 身份与幂等键、受控重试、结果校验，客户端保留来源与录音。不要为修复失败绕过安全/数据校验或无限重试扣费。

APP 的固定学习正文、进度、词义状态等长期权威在 Android 本机加密存储；服务端只保留允许的最小状态及任务资料。这次上传的是**开发项目资料**，没有把用户手机学习库改为云端同步，也不包含用户学习数据库。

现有 API 是原 Mac 的局域网服务。`.local`＋DNS-SD `_reallanguage._tcp.`/Android NSD 可应对同一可互访局域网 DHCP 改址，不能穿透跨城市网络、Mac 关机或路由隔离。长期异地使用需要稳定公网 HTTPS 后台或另外配置受控远程网络；本次文档上云不等于该部署已完成。
