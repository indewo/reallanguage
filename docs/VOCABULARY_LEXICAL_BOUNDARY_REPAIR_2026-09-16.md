# 词汇本词法边界修复（2026-09-16）

## 问题原因

学习目标原先只校验目标文字是否能在确认英语中找到，没有校验 `WORD` 或
`FIXED_EXPRESSION` 是否其实覆盖了完整句子。只要生成服务把整句错误标成固定
表达，固定、学习归档和词汇本读取都会继续接受。历史记录中的字符串 `"null"`
也没有被当作空音标净化，因此会直接显示在词汇卡片上。

## 修复边界

- 服务端生成解码拒绝把完整陈述句或问句标成词汇目标。
- Android 生成结果与固定计划再次执行相同校验，避免旧服务或异常响应绕过。
- 学习完成归档前第三次校验；历史坏目标不写入词汇本，但不阻塞章节保存。
- 词汇本读取隔离已经存在的整句型坏记录，不删除其他用户数据。
- 数据库空值、空字符串及不区分大小写的 `"null"` 均不再显示为音标或元数据。

## 回归样例

`Can you hear what I'm saying right now?` 作为 `WORD` 或
`FIXED_EXPRESSION` 均必须失败；作为完整学习句仍可正常保留和学习。

后续导入 CET-4、CET-6、TOEFL、IELTS 等正式词表后，词表用于细化学习范围与
词汇归属，不替代本次“完整句绝不是词汇项”的基础边界。

## 局域网交付

Android v62 使用稳定的 Bonjour 主机名 `EricdeMacBook-Pro.local:3000`，不再把
Wi-Fi 临时分配的 `192.168.*` 或 `10.*` 地址写死在安装包中。
